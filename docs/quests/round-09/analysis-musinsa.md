## 1. 랭킹 재계산 주기: 30분 (3탭 공통)

- 서버 `updatedAt` 기준 매시 **~:13, ~:43분**에 재계산
- 평균 간격: **30.0분** (범위 29.4~30.4분)
- **심야 04~07시**: 재계산 주기가 60~90분으로 늘어남 (트래픽 감소 시 계산 빈도 축소)
- 재계산 방식: 아이템 선정 + 순위 결정이 **원자적** (부분 업데이트 없음)
- epoch 내(갱신과 갱신 사이): **완전 정적** (순위 변동 0건)

## 2. 탭별 교체 패턴

### all (전체)

| 항목 | 값 |
|------|-----|
| 교체 시점 | 19회 (10.3시간) |
| 평균 교체 규모 | 40~60개 / 101개 |
| 교체율 | 40~60% |
| 전체 유니크 아이템 | 606개 |
| 전체 기간 불변 | **1개** (데이 - 크롭 스웨이드 자켓) |

- 가장 표준적인 교체 패턴
- 심야(03~07시) 잔존률이 28~47%까지 하락 (트래픽 감소 반영)

### new-up (NEW/UP)

| 항목 | 값 |
|------|-----|
| 교체 규모 | 40~96개 / 101개 |
| 교체율 | 39~94% (최고 회전율) |
| 전체 유니크 아이템 | **944개** |
| 전체 기간 불변 | **2개** (나이키 LD-1000, 데이 크롭 자켓) |

#### A형/B형 전환 현상

- **A형 (킨치 지배)**: 22:42 ~ 01:43 — 킨치 5~7개가 TOP 10 독점, "급상승" 라벨
- **B형 (다양 브랜드)**: 01:43 ~ 09:19+ — 킨치 0~2개, 다양한 브랜드
- 실제로는 **A→B 단방향 전환이 1회** 발생 (관측 내 B→A 복귀 없음)

#### B-flash 현상

- 30분 사이클 종료 **직전 ~3분**에 B형 랭킹이 일시 노출 후 복귀
- 이전 분석에서 "A/B가 번갈아 나타남"으로 보였던 것은 이 B-flash 현상
- 추정: 캐시 만료 시 실시간 계산 결과가 과도 상태로 일시 노출

### up-quickly (급상승)

| 항목 | 값 |
|------|-----|
| 교체 규모 | 7~16개 / 101개 |
| 교체율 | **~12%** (최저 회전율) |
| 순위 변동 아이템 | 72~80개 / 재계산 |
| 전체 유니크 아이템 | 347개 |
| 전체 기간 불변 | **20개** |

- 아이템 교체는 적지만, **유지 아이템 내 순위 변동이 매우 격렬**
- "이미 상승 추세가 확립된 상품"이므로 관성이 크고 교체 리스크 낮음
- Flash 현상: 00:44, 01:14에 78~97% 교체 후 3~6분 내 복구

## 3. 소셜 지표 갱신: ~30분

| 지표 | 갱신 주기 | 특징 |
|------|----------|------|
| 조회수 ("N명이 보는 중") | ~30분 | 97~100개 아이템 동시 변경 |
| 구매수 ("N명이 구매 중") | ~30분 (조회수와 다른 시점) | 16~36개 아이템 소량 갱신 |

- 랭킹 재계산과 **독립적** (같은 epoch 내에서도 숫자만 변동)
- 심야로 갈수록 급감 (예: 6,800명 보는 중 → 745명)

---

## 4. 가격 변동: 0건

- 10시간 동안 606개(all) / 944개(new-up) / 347개(up-quickly) 전체 상품의 가격/할인율 **완전 불변**
- 가격은 랭킹과 무관한 별도 주기(일 단위 이상)로 관리

---

## 5. 광고 슬롯

- rank=0 (또는 13위 삽입) 아이템이 **매 3분(매 호출)마다 교체**
- **53개** 캠페인이 랜덤/가중치 기반 로테이션
- 고정 순서가 아닌 랜덤 배분 (동일 광고가 비연속적으로 반복)
- 가장 많이 노출된 광고: 각 5회/118회

---

## 6. TOP 10 안정성

### all
- 매 재계산 시 TOP 10 내 평균 교체: 2~3개
- 킨치가 TOP 10 중 7~8자리 독점

### new-up
- A형: 킨치 6개 고정 + 나머지 4개 변동
- B형: 킨치 0~1개, 완전히 다른 구성

### up-quickly
- TOP 10 매 주기 교체: 평균 **1.1개** (가장 안정적)
- 킨치 5~6개 고정 (1~5위 완전 고정)
