## 1. 랭킹 재계산 주기

| 서비스 | 기본 주기 | 재계산 시각 | 심야 변동 |
|--------|----------|-----------|----------|
| **29CM** | **1시간** | 매시 ~:43분 | 변동 없음 (일정) |
| **무신사** (3탭 공통) | **30분** | 매시 ~:13, ~:43분 | 04~07시 60~90분으로 늘어남 |

- 무신사가 29CM 대비 **2배 빈번하게** 재계산
- 두 서비스 모두 재계산 시 **목록과 순위를 원자적으로 확정** (부분 업데이트 없음)
- epoch 내(갱신~갱신 사이)에서는 **완전 정적 캐시 반환** (순위 변동 0건)

## 6. 무신사 전용 특징

### 광고 슬롯
- rank=0 아이템이 **매 3분(매 호출)마다 교체**
- 53개 캠페인이 랜덤/가중치 기반 로테이션
- 29CM에는 이 패턴 없음

### Flash 현상 (new-up, up-quickly)
- 30분 사이클 종료 직전 ~3분에 **전혀 다른 랭킹**이 일시 노출 후 복구
- new-up: A형(킨치 지배) → B형(다양 브랜드) 전환의 과도 상태
- up-quickly: 78~97% 교체 후 3~6분 내 원복
- 추정: 캐시 만료 시 실시간 계산 결과가 일시 노출

### 탭별 독립 랭킹 엔진
- 3개 탭이 동일 30분 주기로 갱신하되, 각자 독립적인 랭킹 로직 수행
- all: 매출/조회수/후기수 종합
- new-up: 신규 진입 + 상승 가중치 (킨치 프로모션 영향 가능성)
- up-quickly: 급상승 모멘텀 기반

## 7. 아키텍처 추정 비교

| 항목 | 29CM | 무신사 |
|------|------|--------|
| 랭킹 엔진 | 1시간 배치 | 30분 배치 (심야 축소) |
| 소셜 지표 | 5분 독립 갱신 | ~30분 독립 갱신 |
| 캐시 전략 | epoch 내 완전 정적 | 동일 (epoch 내 정적) |
| 가격 갱신 | 일 단위 (자정 전후) | 별도 주기 (일 단위+) |
| 광고 삽입 | 없음 | 매 호출 로테이션 (53개 캠페인) |
| 탭별 분리 | 단일 랭킹 | 3개 독립 랭킹 엔진 |
| 자정 리셋 | 있음 (periodSort=NOW) | 없음 |
| 재계산 방식 | 원자적 (목록+순위 동시 확정) | 동일 |

## 8. 설계 시사점

### 공통 패턴
1. **랭킹 계산과 소셜 지표를 분리**: 무거운 랭킹 재계산(30분~1시간)과 가벼운 지표 갱신(5~30분)을 독립 주기로 운영
2. **원자적 갱신**: 목록 선정 + 순위 결정을 한 번에 수행하고 캐시에 저장, 중간 상태 노출 최소화
3. **가격은 랭킹과 무관**: 가격 변동이 랭킹 재계산 시점과 일치하지 않음 → 별도 관리

### 29CM 특징
- 1시간 주기로 충분히 안정적인 랭킹 제공
- 자정 리셋 설계 → "오늘의 베스트" 성격 강조
- 소셜 지표 5분 갱신 → 실시간 인기 체감 제공

### 무신사 특징
- 30분 주기로 더 빈번한 갱신 → 빠른 트렌드 반영
- 3개 독립 탭으로 다양한 관점의 랭킹 제공
- 광고 슬롯을 랭킹 내에 자연스럽게 삽입
- Flash 현상 → 캐시 전환 시 과도 상태 존재 (개선 여지)
