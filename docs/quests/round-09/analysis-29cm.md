- 자정 후(00~03시) 평균 교체 규모: **48개** (100개 중)
- `periodSort=NOW`가 "오늘" 기준 집계이므로, 일자 변경 시 계산 기간 자체가 리셋되어 교체 폭이 약 2배 급증

## 2. 소셜 지표 갱신 주기: 5분

### heartCount
- 정확히 **5분 간격**으로 갱신
- 랭킹 순위와 **독립적**으로 갱신 (순위 불변 구간에서도 heartCount는 변동)
- 아이템 2178417 기준: 6.2시간 동안 18,447 → 19,170 (+723)
- 새벽 시간대(02~03시)로 갈수록 변경 아이템 수 감소 (사용자 활동량 감소 반영)

### reviewCount
- heartCount와 **동일한 5분 주기**에 갱신
- 리뷰 작성 빈도가 낮아 실제 변경은 드묾: 301개 유니크 아이템 중 31개만 변경
